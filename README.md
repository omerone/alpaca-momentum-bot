# בוט מסחר — מדריך למי שרוצה להבין מה קורה כאן

בוט שקונה מניות שכבר בתנועה למעלה, שם להן "רצפה" אוטומטית, ומוכר לפני סוף היום.
רץ על **חשבון Paper של Alpaca — כסף דמה**, עם לוח בקרה בעברית בדפדפן.

---

## בשורה אחת: מה הבוט עושה

1. **סורק** את המניות שסימנת בלוח הבקרה, כל 3 שניות.
2. **קונה** מניה שעולה עכשיו, עם נפח מסחר חריג, ומעל המחיר הממוצע של היום (VWAP).
3. **שם סטופ** — מחיר רצפה שבו מוכרים אוטומטית. הרוחב שלו נקבע לפי כמה המניה תזזיתית (ATR), לא אחוז קבוע.
4. **מטפס עם הרווח** — כשהמניה עולה, הרצפה עולה איתה (טריילינג סטופ).
5. **סוגר הכל** ב-22:55 שעון ישראל. הבוט לא לן עם פוזיציות.

הוא קונה **רק** בין 16:35 ל-18:00 שעון ישראל. אחרי זה השוק מדשדש ורק אוכל סטופים.

## הפעלה

```bash
cd "trading bot"
source .venv/bin/activate
python server.py
```

פותח את לוח הבקרה ב-<http://localhost:5050>. הכתובת מודפסת בטרמינל עם הטוקן.
אחרי שינוי בקוד Python: `./restart.sh` (מרים מחדש בלי להשאיר תהליך יתום).

לפתיחה בטלפון — כפתור 📱 בלוח הבקרה מציג QR (או `python connect.py`).

**התקנה ראשונה בלבד:**

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # ואז ערוך והכנס מפתחות מ-Alpaca
```

את המפתחות מקבלים ב-[Alpaca Paper Trading](https://app.alpaca.markets/paper/dashboard/overview) → API Keys.

## שיהיה חי גם אחרי אתחול

השומר שבתוך הבוט מטפל בתהליכון שמת או נתקע, אבל הוא לא יכול להחיות את התהליך
שלו עצמו. ב-26/08/2026 המק כובה והבוט היה מושבת 30 שעות — שני ימי מסחר.

```bash
cp com.omermaoz.tradingbot.plist ~/Library/LaunchAgents/
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.omermaoz.tradingbot.plist
```

`RunAtLoad` מרים אותו בכניסה למשתמש, `KeepAlive` מחזיר אותו תוך שניות מכל
מוות — אתחול, קריסה או `kill -9`. לבדיקה: `kill -9` על התהליך, והוא חוזר לבד.

```bash
launchctl print gui/$(id -u)/com.omermaoz.tradingbot | grep -E "state|pid|runs"
launchctl bootout gui/$(id -u)/com.omermaoz.tradingbot     # לכיבוי
```

**מה שזה עדיין לא פותר:** מק כבוי או ישן לא מריץ כלום. הרצה רציפה באמת דורשת
מכונה שלא נכבית.

## מה כל קובץ עושה

| קובץ | תפקיד |
|---|---|
| `server.py` | השרת + לוח הבקרה. **זה מה שמריצים.** מפעיל ומכבה את הבוט |
| `main.py` | הלולאה של הבוט: סרוק → קנה → נהל סטופים → סגור |
| `scanner.py` | מוצא מי במומנטום: עלייה + נפח חריג + מעל VWAP |
| `strategy.py` | חישוב הסטופים — ראשוני, טריילינג, ומתי מוכרים |
| `broker.py` | הדיבור מול Alpaca: הזמנות, פוזיציות, מחירים |
| `config.py` | **כל ההגדרות.** רוצה לשנות משהו — כאן |
| `dashboard.html` | לוח הבקרה בעברית (עמוד יחיד, בלי שרת נוסף) |
| `journal.py` | יומן העסקאות ב-SQLite — הבסיס למסך "ביצועים" |
| `postmortem.py` | **החקירה היומית** — נתיחת כל עסקה, סריקת הגדרות, ומסקנות |
| `opening_intel.py` | מודיעין הפתיחה: גאפ, RVOL, נפח פרה-מרקט. **תצוגה בלבד** |
| `earnings_guard.py` | חוסם כניסות ביום דוחות של מניה |
| `minute_data.py` | הורדת נרות דקה + מטמון ב-`data/` |
| `reset.py` | ניקוי: סוגר פוזיציות ומאפס מצב |
| `connect.py` | QR לפתיחת הלוח בטלפון |
| `restart.sh` | הרמה מחדש של השרת |
| `examples/` | בקטסטים — בדיקות "מה היה קורה אילו" מחוץ לבוט החי |

## ההגדרות שבאמת משנות (`config.py`)

| הגדרה | ערך | מה זה |
|---|---|---|
| `scan_universe` | 33 מניות | הרשימה שאפשר לבחור ממנה בלוח הבקרה |
| `max_positions` | 5 | כמה מניות במקביל |
| `risk_pct_per_trade` | 1.0% | כמה מהתיק מסתכנים בכל עסקה — זה מה שקובע את הכמות |
| `max_position_value_usd` | $25,000 | תקרה לעסקה בודדת |
| `min_position_usd` | $1,000 | רצפה לעסקה. פוזיציה קטנה מזה = שבריר מניה, ו-Alpaca לא מאפשר להציב עליה סטופ |
| `atr_stop_mult` | 0.5 | רוחב הסטופ = חצי מהתנועה היומית הממוצעת |
| `atr_trail_mult` | 0.35 | כמה הטריילינג עוקב מתחת לשיא |
| `entry_start_et` / `entry_end_et` | 09:35–11:00 ET | חלון הקנייה (16:35–18:00 שעון ישראל) |
| `eod_close_et` | 15:55 ET | סגירת הכל (22:55 שעון ישראל) |
| `spy_gate_enabled` | `True` | לא קונים כששוק כללי (SPY) מתחת ל-VWAP שלו |
| `earnings_day_veto` | `True` | לא נכנסים למניה ביום הדוחות שלה |
| `intel_enabled` | `False` | מודיעין הפתיחה — תצוגה בלבד, לא מסנן |

**למה `intel_enabled = False`?** בדקנו בבקטסט (12/08/2026): סינון לפי RVOL וגאפ הוריד את הרווח
מ-‎+1,308$ ל-‎+7$. הסיבה — הפילטרים האלה מיועדים לסריקה של אלפי מניות, ועל רשימה קטנה של מניות
גדולות הם רק זורקים עסקאות טובות. המספרים עדיין מוצגים בלוח כי הם מידע שימושי לעין, לא להחלטה.

## החקירה היומית (`postmortem.py`, מסך "חקירה")

כל יום ב-23:20 המערכת מריצה מחדש כל עסקה שנסגרה, מול נרות הדקה של אותו יום. שלוש שכבות:

**1. נתיחה** — לכל עסקה: כמה היא הגיעה בשיא בזמן שהחזקנו, כמה שמרנו מהתנועה, לאן המניה הלכה
אחרי שמכרנו, ומה היה קורה אילו החזקנו עד הסגירה. כל עסקה מקבלת פסק דין: "יצאנו מוקדם" /
"סטופ צר מדי" / "החזרנו את הרווח" / "יציאה טובה" / "תקין".

**2. סריקת הגדרות** — לוקח את הכניסות שהבוט באמת עשה ומריץ אותן מחדש עם רוחב סטופ וטריילינג
שונים. אותן כניסות בדיוק, יציאות אחרות — כך "הסטופ הרגיש צר" הופך למספר. ה-ATR של אותו יום
משוחזר מהסטופ הראשוני שנרשם, אז לא צריך להוריד נתונים נוספים.

**3. מסקנות** — המערכת **שותקת** עד שיש לפחות 20 עסקאות על פני 10 ימי מסחר. פחות מזה, יום
חריג אחד נראה כמו חוק. כשיש מספיק, היא מציגה המלצה קונקרטית (`atr_trail_mult: 0.35 → 0.5`)
עם הראיות שמאחוריה. **היא לעולם לא משנה את `config.py` — השינוי הוא בידיים שלך.**

יוצא דופן אחד שלא מחכה למדגם: אם היציאה בפועל רחוקה ביותר מ-0.3% ממה שחוקי המערכת מחייבים,
זה מדווח מיד. זה לא לקח על השוק אלא סימן לבאג ביצוע — וכך בדיוק נמצא באג היומן ב-17/08/2026.

## מונחים

**פוזיציה** — מניה שקנינו ועוד מחזיקים ·
**סטופ** — מחיר רצפה שבו מוכרים אוטומטית ·
**טריילינג סטופ** — רצפה שמטפסת עם המניה ·
**VWAP** — המחיר הממוצע ששולם היום; מעליו הקונים שולטים ·
**ATR** — כמה המניה זזה ביום ממוצע ·
**גאפ** — הפרש בין הפתיחה לסגירת אתמול ·
**RVOL** — פי כמה מהרגיל נסחר עכשיו ·
**פרה-מרקט** — מסחר לפני הפתיחה (11:00–16:30 שעון ישראל); הבוט לא נוגע ·
**Profit Factor** — סך הרווחים חלקי סך ההפסדים; מעל 1 = רווחי ·
**Paper** — כסף דמה

יש מילון מלא גם בתוך לוח הבקרה, בתחתית מסך "מסחר".
